# تفعيل الدومين www.kob.com عبر AWS Route 53

## التشخيص
الدومين غير مفعّل منذ أكثر من 18 ساعة لأن سجلات DNS المطلوبة غير موجودة عند مزوّد DNS الفعلي (AWS Route 53):

```text
الحالة الحالية:
  A record www.kob.com        → يشير إلى 23.185.0.1 (قديم/خاطئ)
  TXT  _lovable.www.kob.com   → غير موجود
  AAAA www.kob.com            → يشير لعنوان IPv6 قديم (2620:12a:8000::1 ...) — متضارب

المطلوب:
  A record www.kob.com        → 185.158.133.1
  TXT  _lovable.www.kob.com   → lovable_verify=f6824278568f805f686e70fb79552bb171d509df75832bdab3bac36ff98f3fdc
```

## الخطوات (عندك في Route 53 — تغيير يدوي من طرفك، لا أستطيع تنفيذه)
1. افتح AWS Console → Route 53 → Hosted zones → kob.com.
2. عدّل سجل **A** الخاص بـ `www` ليصبح `185.158.133.1` (بدل 23.185.0.1).
3. احذف سجل **AAAA** الخاص بـ `www` (يشير لخادم آخر وقد يتجاوز سجل A عند بعض الزوار).
4. أضف سجل **TXT** جديد:
   - Name: `_lovable.www.kob.com`
   - Value: `lovable_verify=f6824278568f805f686e70fb79552bb171d509df75832bdab3bac36ff98f3fdc`
5. احفظ وانتظر الانتشار (عادة دقائق، حتى 72 ساعة كحد أقصى). سيتم التحقق وإصدار شهادة HTTPS تلقائيًا.

## ما سأفعله أنا
- بعد أن تضيف السجلات، أعيد فحص الدومين وأؤكد التفعيل.
- اختياري: إضافة النطاق الأساسي `kob.com` أيضًا حتى يعمل بدون www (يحتاج سجل A `@ → 185.158.133.1` + سجل تحقق خاص به).

## ملاحظة تقنية
- المنشور: المشروع منشور بالفعل، فور تحقق DNS سيبدأ الدومين بالخدمة مباشرة.
- نطاق البريد notify.kob.com لا يزال بانتظار سجلات NS الخاصة به في Route 53 أيضًا (تظهر قيمها في Cloud → Emails) — رسائل رمز التحقق لن تُرسل حتى يكتمل تحققه.
